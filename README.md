# 数学建模项目：高性能芯片热管理系统

本项目用于整理数学建模竞赛中的题目、数据、程序、图表和论文成果。

## 目录结构

```text
├─ 编程/       Python、MATLAB 等建模与分析代码
├─ 数据/       原始数据、清洗后数据和中间数据
├─ 图表/       绘图脚本输出的图片、表格和可视化结果
├─ 论文/       LaTeX/Word 论文源文件及最终稿
├─ 文档/       题目、附件、参考资料
├─ 结果/       模型运行结果、汇总报告和最终交付物
└─ README.md
```

## 推荐工作流

1. 将原始资料放入 `文档/`，原始数据放入 `数据/`。
2. 在 `编程/` 中编写数据处理、建模、求解和绘图代码。
3. 将生成的图片和表格保存到 `图表/`，关键运行结果保存到 `结果/`。
4. 在 `论文/` 中维护论文源文件和最终版本。
